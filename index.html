Powder Lab v3 — Upgrade Log

A modernized rebuild inspired by Dan-Ball's Powder Game 2 (dust2).

v3 Engine Upgrades

  • Typed-array cellular engine — 240×140 grid simulated at 60 FPS
  • Liquid density: oil floats on water, mud sinks, lava is heaviest
  • Chain-reaction explosions (gunpowder + TNT detonate each other)
  • Chemistry pass: salt → seawater, acid corrosion, lava ↔ water → stone, mud drying, virus infection
  • Gravity toggle (zero-G drifting), adjustable speed (×1–×3)
  • Save / Load to browser storage + PNG screenshot export
  • Modern dark UI with categories, tooltips, hover inspector and FPS counter

Compared to Powder Game v2

  • No Java applet — pure single-file HTML5, runs anywhere
  • Smoother liquids with dispersion, alternating scan to remove bias artifacts
  • Better fire model: life-based flame colors, ignition chances per material
  • Quality-of-life: keyboard shortcuts, pen slider, right-click erase
